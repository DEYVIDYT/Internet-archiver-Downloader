# Internet Archiver Downloader

**Internet Archiver Downloader** é um aplicativo simples e direto que funciona como um gerenciador de downloads para o [Internet Archive](https://archive.org/).

Com ele, você pode:

- Fazer login com sua conta do Internet Archive.
- Baixar arquivos de coleções que requerem autenticação.
- Gerenciar facilmente seus downloads.

## Funcionalidades

- Autenticação com conta do Internet Archive.
- Download de arquivos protegidos por login.
- Interface simples e fácil de usar.

## Requisitos

- Conta no Internet Archive
- Conexão com a internet

## Como usar

1. Faça login com sua conta do Internet Archive dentro do app.
2. Navegue até a coleção desejada.
3. Inicie o download dos arquivos disponíveis.
